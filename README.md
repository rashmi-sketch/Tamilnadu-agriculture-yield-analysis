# 🌾 Tamil Nadu Agriculture Yield Analysis

> **Power BI Dashboard | Agricultural Production & Yield Analytics**

## 📊 Project Overview

This project analyzes agricultural yield data across Tamil Nadu using Power BI.

The analysis explores crop yield patterns across districts, crops, seasons and years, with the goal of turning agricultural data into clear and actionable insights.

---

## 🎯 Objectives

- Analyze agricultural yield across Tamil Nadu
- Compare crop performance across districts
- Study seasonal yield patterns
- Identify high- and low-performing crops
- Analyze year-wise agricultural trends
- Create an interactive dashboard for agricultural insights

---

## 🛠️ Tools & Technologies

- Power BI
- DAX
- Power Query
- Data Modeling
- Excel
- Data Visualization

---

## 🗂️ Data Model

The project uses a structured dimensional model with:

- `Fact_Yield`
- `Dim_Districts`
- `Dim_Crops`
- `Dim_Season`
- `Data_Dictionary`
- `DAX_Measures`

The model is designed to support interactive analysis across crops, districts, seasons and years.

---

## 📈 Dashboard Analysis

The dashboard focuses on:

### 🌱 Crop Analysis
Comparison of yield across different crops.

### 📍 District Analysis
Analysis of agricultural yield across Tamil Nadu districts.

### 🌦️ Seasonal Analysis
Comparison of yield across different agricultural seasons.

### 📅 Year-wise Analysis
Identification of changes and trends in agricultural yield over time.

---

## 🔍 Key Analytical Questions

- Which crops have the highest yield?
- Which districts perform best?
- Which districts have lower agricultural yield?
- How does yield vary by season?
- How has agricultural yield changed over time?
- Which crop and district combinations show strong performance?
